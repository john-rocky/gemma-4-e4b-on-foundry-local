Speed measured again with High QoS, 2026-11-11, Windows 11 build 26200.9711, on the same laptop and drivers as
the published numbers. This file lists each timed process of the form below.

Power settings during these runs: MSI Center's User Scenario on Balanced (set at 20:42 on 11-10), Windows' power
mode on its default (no power mode overlay), on AC power. The published numbers of 2026-11-06 were measured with
MSI Center's earlier setting (not Extreme Performance; which setting it was is not recorded);
results/speed_high_qos_1109_webgpu_igpu.txt was measured on Extreme Performance.

The int4 package: Hugging Face mlboydaisuke/gemma-4-E4B-it-Foundry-Local at 9d1751f, cuda-int4-8k/, with
context_length and search.max_length set back to 131072, and every session on WebGPU with adapter 0, the RTX
(variant_pkg.py, as in step 11). Python: the versions of requirements-genai.txt.

How: every timed run is a new Python process started over ssh (Win32_Process.Create); the sitting line below gives
the desktop's state (LogonUI = Windows' lock-screen process).
It runs the published script unchanged (runpy), with the published number's arguments.
High QoS = the process calls SetProcessInformation(ProcessPowerThrottling, ControlMask = EXECUTION_SPEED,
StateMask = 0) at its start, before the published script and its imports run (the wrapper imports only ctypes,
json, os, sys and time before the call); default = no call. Each process reads the state back
(ControlMask/StateMask) at its start and at its end, and times a fixed 30,000-iteration Python loop at its start
and three times at its end (the end value below is the fastest of the three, with the core type it ran on).
genai_speed.py ends a WebGPU run with os._exit(0); the wrapper takes its end readings in a hook on that call.
State 1/0 = power throttling opted out (High QoS); 0/0 = nothing set.
Order: High, default, default, High. A row's value = the mean of its two processes of one QoS.
Control right before and right after the form: a static fp16 graph on the Intel GPU (Windows ML, OpenVINO EP,
101 tokens, default QoS), known 98.2 ms; the form counts when both controls are within 5 % of it.
A control before a form that is more than 5 % off is run once more after 90 s of idle; a control after a form is
not repeated. Here the control before, right after another form, first read 104.7 ms (+6.7 %); the sitting line
below gives its second run.
Other forms timed the same night are not listed: GenAI's int4 on CUDA without CUDA graphs ran as a check against
results/speed_high_qos_1109.txt, and its High and default means came within 5 % of it (60.43 against 58.40, 36.89
against 36.94); for the others, a control next to them was more than 5 % off, or the time reserved for the form ran
out after two of its four processes.
